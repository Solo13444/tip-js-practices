## 1. Окружение и запуск

Работа подготовлена для Windows 10, редактора кода и браузера Chrome/Edge. Перед сдачей впишите фактические версии команд `node --version`, `npm --version` и `git --version` на своём компьютере:

- Node.js: `указать фактическую версию`
- npm: `указать фактическую версию`
- Git: `указать фактическую версию`
- Браузер: Chrome или Edge, фактическую версию указать при сдаче.

Команды выполняются из корня репозитория:

```powershell
node practice-01/js/hello.js
node practice-01/js/types.js
node practice-01/js/progress.js
node practice-01/js/plan.js
node practice-01/js/debug.js
```

Для браузера откройте `practice-01/index.html`, затем откройте DevTools клавишей F12 и вкладку Console. Для исследования другого файла временно поменяйте путь `script` в `index.html`, сохраните файл и перезагрузите страницу. Перед сдачей верните `./js/hello.js`.

## 2. Задание 1. Различия сред выполнения

Один файл `hello.js` запускается как в Node.js, так и в браузере. Сообщения `console.log` выводятся в терминал Node.js или в консоль DevTools браузера. Ожидаемое значение `typeof document` различается: в обычном браузере это `object`, а в Node.js — `undefined`, потому что объект `document` предоставляется DOM браузера.

## 5. Задание 4. План выполнения по дням

Для варианта 4: всего 20 задач, выполнено 11, дневной лимит 6. Остаётся 9 задач, поэтому план состоит из двух дней.

```text
Осталось задач: 9
День 1: выполнено 6, осталось 3
День 2: выполнено 3, осталось 0
Потребуется дней: 2
```

В цикле `while` на каждой итерации уменьшается остаток. Для последнего дня используется меньшее из дневного лимита и оставшегося количества, поэтому остаток не становится отрицательным. Перед циклом отдельно проверяется дневной лимит, даже если все задачи уже выполнены.

## 6. Задание 5. Отладка логических ошибок

В исходной версии выражение `completedText + additionalText` объединяло строки и давало `"32"`. Затем остаток вычислялся как `8 - 32`, то есть `-24`. В исправленной версии обе строки преобразуются в числа, поэтому `3 + 2 = 5`, остаток равен `8 - 5 = 3`.

В исходном цикле условие `taskNumber < 4` исключало четвёртый номер, поэтому сумма равнялась `1 + 2 + 3 = 6`. После замены на `taskNumber <= 4` сумма равна `1 + 2 + 3 + 4 = 10`.

| Ошибка | Наблюдение в исходной версии | Причина | Исправление | Результат |
|---|---|---|---|---|
| Сложение количества задач | `Выполнено: 32`, `Осталось: -24` | `+` объединял две строки. | `Number(completedText) + Number(additionalText)` | `Выполнено: 5`, `Осталось: 3` |
| Граница цикла | Контрольная сумма `6` вместо `10`. | Условие `< 4` не включало четвёртую итерацию. | Заменить условие на `<= 4`. | `Контрольная сумма: 10` |

**Скриншот отладки:** после локального запуска откройте `debug.js` в DevTools → Sources, установите точку останова и сохраните изображение в `practice-01/screenshots/debug-breakpoint.png`. Этот скриншот должен быть получен в вашем браузере: заранее подставленное изображение не подтверждало бы фактическую отладку.
